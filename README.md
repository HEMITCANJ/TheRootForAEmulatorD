## What this app's Function 🤔
This app is used to distribute Root access for virtual machines that are not easy to root.
For example, the very useful AEmulator simulator.

## How to use this app🧐?
### Stop.1
Open your **AEmulator**, select a hardware profile, load it and wait for startup to complete.

### Stop.2
Install this app inside the virtual machine.

### Stop.3
Install **Shizuku**. Then activate Shizuku via ADB Shell with root privilege.

### Stop.4
Open Shizuku and authorize this app.

### Stop.END
Inside this app, grant superuser (root) privileges to the target applications you need.

## Q&R
### What is 'Magisk'?
> [Magisk](https://github.com/topjohnwu/Magisk) is an open-source root access management tool developed by topjohnwu and hosted on GitHub.
> If you are in mainland China and cannot access GitHub, you can try downloading it from the Chinese Magisk community: [Magisk中文网](https://magiskcn.com/).

### What is 'AEmulator'?
> [AEmulator](https://aemulator.fun/)'s slogan: *Run classic Android firmware — HTC Sense, TouchWiz, MIUI, AOSP — on a modern phone. No root, no PC.*
> You can get releases at [Github Release](https://github.com/uxazu/aemulator/releases).
> For more resources, visit the [AEmulatorForum](https://forum.aemulator.fun/).
> There is also an improved fork: [AEmulatorPlus](https://github.com/somerandomusernam2/AEmulator-Plus), which may be a better choice.
